# Examples / 示例项目

## demo_cnc — 完整导出示例

展示 QmlVcp Builder **可视化编辑 → 导出**后生成的完整 CNC 人机界面项目结构。

包含：DRO坐标、JOG控制、程序启停、急停上电、主轴信息、自定义属性等全部常用功能演示。

---

Demonstrates the complete CNC HMI project structure generated by QmlVcp Builder after visual editing and exporting.

Includes: DRO display, JOG control, cycle start/stop, E-stop, spindle info, custom properties — all common CNC UI features.
