# Assets 素材目录

将你的按钮贴图、背景图、图标等 PNG/SVG 文件放在此目录。

## 建议尺寸

| 类型 | 建议尺寸 |
|------|---------|
| 全屏背景 | 与界面等大 (如 1024x768) |
| 功能按钮 | 80x80 ~ 150x150 |
| JOG 方向键 | 60x60 ~ 80x80 |
| 状态图标 | 24x24 ~ 48x48 |

## QML 引用方式

```qml
Image {
    source: "assets/btn_start.png"
}
```

Builder 导出时会自动从你的原始素材目录复制文件到此。
